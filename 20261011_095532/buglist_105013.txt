[LOW] Dead local + latent double-invoke null deref in resolveTrap
================================================================================
Location: index.html:1789 (`var enc=G.activeEncounter.enc;`).
Explanation: `enc` is now unused (the spring branch no longer reads `enc.effect`). More
importantly, if the encounter modal's button handler fires twice before the modal is dismissed
(e.g. a rapid double-tap; mkBtn's click handler calls the resolver directly and G.activeEncounter
is nulled at the end of the first invocation), the second call dereferences
`G.activeEncounter.enc` → TypeError. This mirrors the old resolvePuzzle, so it is pre-existing,
not a regression, but the fix made the dereference pointless.
Fix approach: delete line 1789; read `enc.id` only where needed, or guard
`if(!G.activeEncounter) return;` at the top of resolveTrap.

[LOW] Trap tier labels land one tier later than declared (informational)
================================================================================
Location: index.html:692 (`trapOffset = depth-2`), index.html:685 (trapPool).
Explanation: With <=2 trap slots per floor, the rotation makes the first trap per floor
deterministic (f2 pressure-plate, f3 collapsing-floor, f4 snap-trap, f5 spider-web, f6 light-glyph),
so a type's first appearance is one tier after its `floor` label; cursed-ward (label f5) appears only
on f6 and only when f6 rolls 2 trap slots (~50% of seeds). direction.txt declares `floor` a tier
label and traps density/region-driven, so this is conformant, but the offset obscures the intended
early→mid→late progression and makes `floor` a weak predictor.
Fix approach (optional): index the pool by tier rather than `depth-2`, or seed trapOffset from a
per-floor hash, so first appearances track the declared tier; add a regression assertion mapping
each trap id to an expected tier window.

================================================================================

Explanation: Audio.trap accepts `far` (g=0.55) to attenuate off-radius cues, but the sole call site

drop the parameter and document that traps cue only on encounter.
