TEST METHOD NOTES
------------------------------------------------------------------------
  • Input fidelity: real mouse down/move/up on desktop viewports; real
    TouchEvent (touchstart/touchmove/touchend, identifier-tracked) on 375x667.
    DOM buttons tapped via Playwright locator.tap() (touch) / click() (mouse).
  • Mid-gesture pause: the #pauseBtn pointerdown handler was invoked while a
    canvas gesture was held, because a held pointer cannot simultaneously move
    onto the pause button in a single-pointer automation model. This exercises
    the identical performAction('pause') path the real button uses.
  • Music instrumentation: AudioContext.prototype.createGain + AudioParam
    prototype hooks label node index 1 as musicBus and record every
    linearRampToValueAtTime command, giving an observable "music is paused"
    signal without access to the closure-scoped Audio object.
  • Determinism: Math.random pinned to 0.05 (all resource tokens) for the
    combo test; 0.95 (enemies) and 0.10 (resources) for the forced end states.
  • Score reads use the HUD text; because the HUD score eases toward the true
    value, deltas carry a <=2-point display-easing tolerance where relevant.
    This does not affect the x8 milestone test, whose repeat signature (+150)
    is an order of magnitude above the tolerance.
